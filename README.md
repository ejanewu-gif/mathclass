# 臺南市國小數學科教學進度 × 學力檢測對照導航平台

> **115 學年度入校輔導專用 · 全國首創單元進度與歷年學測真題縱深對照導航系統**

本專案整合臺南市 109～114 年（全 6 年歷史真題，三、四、五、六年級共 598 題）學力檢測數據庫，精準對照三大主流課本版本（康軒、翰林、南一）之各單元教學進度。

---

## 🌟 核心特色

1. **三維課本進度對照**：
   - 涵蓋康軒、翰林、南一全學段（3～6 年級上學期）各單元。
   - 點擊任一單元即可一秒掌握該單元於歷年學力檢測中的「致命弱點題型」與「全體答對率」。
2. **完整 6 年歷史考題（598 題 · 1,196 幅高解析圖檔）**：
   - 試題原圖（`qXX.png`）與官方輔導團深度補救教學分析長圖（`rem_qXX.png`）全收錄。
   - 含標準答案、整體通過率、鑑別度、4 選項高低分組反應比率及教師課堂教學防雷指引。
3. **🖨️ 學生真題卷列印引擎**：
   - 支援 4 題對稱滿版 A4（2x2 排版），依據答對率梯度智慧挑選最適合課前 3～5 分鐘診斷的精選真題。
4. **極速零相依架構**：
   - 單一靜態網頁（純 HTML + Tailwind CSS + Lucide Icons），支援 GitHub Pages 免費雲端託管，亦支援下載後完全離線瀏覽！

---

## 🚀 部署與線上瀏覽

透過 GitHub Pages 免費託管：
1. 將本專案推送到 GitHub。
2. 進入 Repository 的 **Settings** -> **Pages**。
3. 在 **Build and deployment** 下選擇 **Branch: `main`**，資料夾選擇 **`/(root)`**。
4. 點擊 **Save**，約 1～2 分鐘後即可透過專屬網址線上存取！
